# A11. Citing This Book

If you find this book helpful, cite it in the documents where you used it. Thank you!

**Text format**

> Olivier Cleynen, *Engineering Thermodynamics*. Olivier Cleynen /
> Thermodynamicsbook.com, 2025. ISBN 9781446710067 ; url:
> <https://thermodynamicsbook.com/>

**Bibtex format (.bib)**

```bibtex
@book{cleynen2025thermodynamics,
  author=     {Cleynen, Olivier},
  title=      {Engineering Thermodynamics},
  subtitle=   {International edition with SI units},
  language=   {english},
  publisher=  {Olivier Cleynen / Thermodynamicsbook.com},
  year=       {2025},
  isbn=       {9781446710067},
  annotation= {licensed as Creative Commons BY-SA},
  url=        {https://thermodynamicsbook.com/},
}
```

**Endnote format (.enw)**

```text
%0 Book
%T Engineering Thermodynamics
%A Cleynen, Olivier
%@ 9781446710067
%D 2025
%G English
%I Olivier Cleynen / Thermodynamicsbook.com
%Z Licensed as Creative Commons BY-SA
%U https://thermodynamicsbook.com/
```

**Wikitext format**

```text
<ref name=cleynen2025thermodynamics>{{cite book|last1=Cleynen|first1=Olivier
|title=Engineering Thermodynamics|date=2025
|publisher=Olivier Cleynen / Thermodynamicsbook.com|isbn=9781446710067}}</ref>
```

**HTML format**

```html
Olivier Cleynen, <span style="font-style: italic; font-style: oblique;">
Engineering Thermodynamics</span>, Olivier Cleynen / Thermodynamicsbook.com,
2025. ISBN 9781446710067,
<a href="https://thermodynamicsbook.com/">thermodynamicsbook.com</a>
```
