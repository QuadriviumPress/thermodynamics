# A5. Conversion of Units to SI

The following relationships can be used to convert customary physical units into SI units. The conversion factors here are rounded to seven significant digits.

:::{math}
• The inch :
:::

:::{math}
l(m) = 39.370 08 l(in) (A5/1)
:::

:::{math}
l(in) = 2.54 \times 10^{-2}l(m) (A5/2)
:::

:::{math}
• The foot :
:::

:::{math}
l(m) = 3.280 84 l(ft) (A5/3)
:::

:::{math}
l(ft) = 0.3048 l(m) (A5/4)
:::

:::{math}
• The mile :
:::

:::{math}
l(m) = 6.213 712 \times 10^{-4}l(mi) (A5/5)
:::

:::{math}
l(mi) = 1.609 344 \times 10^{3}l(m) (A5/6)
:::

:::{math}
• The mile per hour :
:::

:::{math}
C(m s^{-1}) = 0.447 04 C(mph) (A5/7)
:::

:::{math}
C(km/h) = 1.609 344 C(mph) (A5/8)
:::

:::{math}
C(mph) = 0.621 371 C(km/h) (A5/9)
:::

:::{math}
C(mph) = 2.236 936 C(m s^{-1}) (A5/10)
:::

:::{math}
• The US gallon :
:::

:::{math}
V(US gal) = 2.641 721 \times 10^{2}V(m^{3}) (A5/11)
:::

:::{math}
V(m^{3}) = 3.785 412 \times 10^{-3}V(US gal) (A5/12)
:::

:::{math}
• The imperial gallon :
:::

:::{math}
V(imp gal) = 2.199 692 \times 10^{2}V(m^{3}) (A5/13)
:::

:::{math}
V(m^{3}) = 4.546 09 \times 10^{-3}V(imp gal) (A5/14)
:::

:::{math}
• The tonne or metric ton :
:::

:::{math}
m(t) = 10^{-3}m(kg) (A5/15)
:::

:::{math}
m(kg) = 10^{3}m(t) (A5/16)
:::

:::{math}
• the pound :
:::

:::{math}
m(lb) = 2.204 623 m(kg) (A5/17)
:::

:::{math}
m(kg) = 0.453 592 37 m(lb) (A5/18)
:::

:::{math}
• the pound - force :
:::

:::{math}
F(lbf) = 0.224 808 9 F(N) (A5/19)
:::

:::{math}
F(N) = 4.448 222 F(lbf) (A5/20)
:::

:::{math}
• the inch of mercury :
:::

:::{math}
p(inHg) = 2.067 099 \times 10^{-6}p(Pa) (A5/21)
:::

:::{math}
p(Pa) = 3.386 389 \times 10^{3}p(inHg) (A5/22)
:::

:::{math}
• the bar :
:::

:::{math}
p(bar) = 10^{-5}p(Pa) (A5/23)
:::

:::{math}
p(Pa) = 10^{5}p(bar) (A5/24)
:::

:::{math}
• the pound per square inch :
:::

:::{math}
p(psi) = 1.450 377 \times 10^{-4}p(Pa) (A5/25)
:::

:::{math}
p(psi) = 14.503 77 p(bar) (A5/26)
:::

:::{math}
p(Pa) = 6.894 757 \times 10^{3}p(psi) (A5/27)
:::

:::{math}
p(bar) = 6.894 757 \times 10^{-2}p(psi) (A5/28)
:::

• the kilogram-force per square centimeter (or kilopond per square centimeter):

:::{math}
p(kg_{f}/cm^{2}) = 1.019 716 \times 10^{-5}p(Pa) (A5/29)
:::

:::{math}
p(kg_{f}/cm^{2}) = 1.019 716 p(bar) (A5/30)
:::

:::{math}
p(Pa) = 9.806 65 \times 10^{4}p(kg_{f}/cm^{2}) (A5/31)
:::

:::{math}
p(bar) = 0.980 665 p(kg_{f}/cm^{2}) (A5/32)
:::

:::{math}
• the degree Fahrenheit :
:::

:::{math}
T(^{\circ} F) = 1.8 \times [T(K) - 273.15] + 32 (A5/33)
:::

:::{math}
T(K) = \frac{T(^{\circ} F) - 32}{1.8} + 273.15 (\mathrm{A}5/34)
:::

:::{math}
• the imperial horsepower :
:::

:::{math}
W(hp imp) = 1.341 022 \times 10^{-3}\dot{W}(W) (A5/35)
:::

:::{math}
W(W) = 7.456 999 \times 10^{2}\dot{W}(hp imp) (A5/36)
:::

:::{math}
• the metric horsepower (din 66036):
:::

:::{math}
W(hp) = 1.359 622 \times 10^{-3}\dot{W}(W) (A5/37)
:::

:::{math}
W(W) = 7.354 988 \times 10^{2}\dot{W}(hp) (A5/38)
:::
